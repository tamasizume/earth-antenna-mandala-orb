# Threads 投稿セット（最初の2週間・14本）

ルール：
- **最初の1週間はリンクなし**（動画・画像・一言だけ）。2週目からリンクを入れる、それも1日1回まで
- 自動投稿・連携は使わない。すべて手で貼る
- 返信・いいねが来たら必ず返す。Threadsは返信のやり取りが表示に一番効く
- 投稿時間は 12:00 か 21:00 のどちらか（日本のスマホ利用が多い時間）

素材：
- 動画：`out/mandala-orb-shorts-captioned.mp4`（縦・字幕入り）、`out/mandala-orb-demo.mp4`（横）
- 画像：`docs/img/mandala-speaking.png` `orb-speaking.png` `mandala-thinking.png`
