# YouTube チャンネル設定（Shorts用）

既存の「地球アンテナ」チャンネルがあればそこに追加。新規なら以下で作成。
YouTube Studio → 設定 → チャンネル → 基本情報 に貼る。

## チャンネル名
地球アンテナ

## ハンドル
@earthantenna（取れなければ @earth_antenna、@tamasizume）

## アイコン（800×800）
noteの見出し画像で使った曼荼羅を正方形に切り出して使う。文字なしの方が小さく表示されたとき綺麗。
（生成する場合の日本語プロンプト）
```
黒い背景の中央に、青白い光の粒子でできた15枚の花びらの曼荼羅。粒子は外側にいくほど紫がかる。文字・ロゴ・日付は入れない。正方形、高解像度、上品で静か。
```

## バナー（2048×1152、中央 1235×338 が安全域）
黒背景の左に曼荼羅、右にオーブ、中央に白文字で「地球アンテナ」。
（日本語プロンプト）
```
横長の黒い背景。左寄りに青白い光の粒子でできた曼荼羅、右寄りにSiri風の白青の光の玉。中央に大きな白いゴシック体で「地球アンテナ」、その下に小さく「ひらめきを形にする」。日付・ロゴは入れない。16:9より横長のバナー、余白多め、上品。
```

## キーワード（設定 → チャンネル → 基本情報）
AI, 音声チャット, ビジュアライザー, JavaScript, 曼荼羅, Claude Code, 地球アンテナ, 生成AI

## Shorts投稿時の共通設定
- タイトルの末尾に `#Shorts`
- 説明文の1行目に一番伝えたい言葉
- 「視聴者：子ども向けではない」
- 公開後、固定コメントにデモのリンクを1つ置く（説明文より押されやすい）

## 投稿順（`shorts-scripts.md` の3本）
| 日 | 本 | 型 |
|---|---|---|
| 1日目 | 1本目 | 問題提起型 |
| 4日目 | 2本目 | 技術者向け |
| 7日目 | 3本目 | 見た目推し |

1週間後、YouTube Studio → アナリティクス で「再生数」「視聴維持率」「表示回数のクリック率」を3本分記録する。
