# YouTube Shorts 投稿セット（3本）

動画は `out/mandala-orb-shorts-captioned.mp4`（1080×1920・24秒・字幕入り）を使います。
3本とも同じ動画でよく、タイトルと説明を変えて反応の違いを見ます。1本目を投稿して2〜3日空け、2本目、3本目。

共通：
- 公開設定「公開」、対象「子ども向けではない」
- 説明文の1行目が検索に効くので、そこに一番伝えたい言葉を入れる
- コメントが付いたら必ず返信（Shortsの表示に効く）

---

## 1本目：問題提起型

**タイトル**（100文字以内）
AIが「聞いてる・考えてる・話してる」を光で見せる #Shorts

**説明文**
AI音声チャットで一番長く感じる「返事を待つ無音」を、光の表情に変えました。
会話の4つの状態（待機／聞き取り／思考中／発話中）で、オーブが自動で変わります。

## 2本目：技術者向け

どのAIにも3行で繋がる音声ビジュアライザー【依存ゼロ・MIT】 #Shorts

## 3本目：見た目推し

**タイトル**
曼荼羅とオーブ、あなたのAIはどっちの顔？ #Shorts

**説明文**
AIアシスタントに「顔」を付けるための音声ビジュアライザー。
15枚の花びらの曼荼羅と、Siri風の光のオーブ。声に合わせて発光・拡大します。
色・密度・花びらの枚数はスライダーで調整できます。
