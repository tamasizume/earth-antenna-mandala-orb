## 2. ココナラ紹介文（出品：AI音声チャットのUI制作・組み込み）

**タイトル案**
AI音声チャットに「話している感」を付けます｜曼荼羅＆オーブの音声ビジュアライザー組み込み

**キャッチ**
無音の数秒を、光の表情に変えます。

**本文**

AI音声チャットを作ったとき、「今AIは聞いているのか、考えているのか、話しているのか」が画面から分からず困ったことはありませんか。

私が制作した曼荼羅＆オーブの音声ビジュアライザーを、あなたのAIチャットに組み込みます。
会話の4つの状態（待機／聞き取り／思考中／発話中）に合わせて、光のオーブが自動で表情を変えます。

▶ 動くデモ: https://tamasizume.github.io/earth-antenna-mandala-orb/

**できること**
- 既存のWebチャット画面（HTML / React / Vue など）へのオーブ組み込み
- Claude / ChatGPT / Gemini / VOICEVOX / ElevenLabs など、お使いのAI・TTSとの接続
- 色・密度・花びらの枚数・反応の強さを、あなたのブランドに合わせて調整
- 曼荼羅／オーブ以外の模様の追加（要相談）

### AIの「今」が見える音声チャットUI

音声チャットで一番長く感じるのは、AIが返事を考えている数秒の無音です。
このパックのオーブは、会話の状態に合わせて自動で表情を変えます。

- 待機中：ゆっくり回転
- 聞き取り中：あなたの声で粒子が輝く
- 思考中：縮んで脈動（考えている演出）
- 発話中：AIの声に合わせて発光・拡大
