AI音声チャットを作ったとき、いちばん困ったのは「今AIは何をしているのか」が画面から分からないことでした。

マイクは拾えているのか。返事を考えているのか。もう話し始めているのか。
テキストのチャットなら「…」で済むところが、音声だと無音の数秒がとても長く感じます。

そこで、会話の状態に合わせて自動で表情を変える光のオーブを作りました。
**AI音声チャットパック 曼荼羅＆オーブ版** として、GitHubで無料公開（MIT）しています。

▶ デモ（ブラウザで動きます）: https://tamasizume.github.io/earth-antenna-mandala-orb/
▶ ソースコード: https://github.com/tamasizume/earth-antenna-mandala-orb

## どんなもの？

（ここにデモ動画 mandala-orb-demo.mp4 を埋め込む）

会話の4つの状態に、それぞれ違う動きが割り当てられています。

| 状態 | 見え方 |
|---|---|
| **待機中** | ゆっくり回転するだけ。音には反応しない |
| **聞き取り中** | あなたの声の大きさで粒子が速く・明るくなる |
| **考え中** | 全体が少し縮んで、ゆっくり脈動する（「待たせている感」の演出） |
| **話し中** | AIの声に合わせて発光・拡大 |

見た目は2パターン。

- **曼荼羅** — 15枚の花びらが対称に広がる粒子模様
- **オーブ** — Siri風の丸い光の玉

密度・感度・花びらの枚数・色は、デモ画面のスライダーで動かしながら決められます。決まったら画面下に出る「組み込みコード」をコピーするだけ。

## 特徴：どのAIにも繋げる

このライブラリは**音声処理を一切持っていません**。

```js
const orb = MandalaOrb.create(canvas, { pattern: 'mandala' });
orb.setState('listening'); // idle / listening / thinking / speaking
orb.setLevel(0.42);        // 音量 0〜1
```

やることはこの2つだけ。「今どの状態か」と「今の音量」を外から渡せば描いてくれます。
だから Claude でも ChatGPT でも Gemini でも、VOICEVOX でも ElevenLabs でも、裏側が何であっても同じ書き方で使えます。

依存ライブラリなし、1ファイル（圧縮版 6KB）、背景は透明なので既存のチャット画面の上にそのまま重ねられます。

## 同梱しているもの

- `mandala-orb.js` / `mandala-orb.min.js` — 本体
- `index.html` — デモ＆調整パネル（自動デモの録画ボタン付き）
- `examples/voice-chat.html` — **ブラウザ内蔵の音声認識＋音声合成だけで実際に会話が動くサンプル**（APIキー不要）。AIの返答部分を自分のAI呼び出しに差し替えれば、そのまま音声チャットになります
- `README.md` — API・調整方法・音量の取り方

## 作った背景

もともとは「地球アンテナ」というポッドキャスト用に、その日の暦のエネルギーを曼荼羅の粒子で描く動画システムを作っていました。その曼荼羅を「AIの声に合わせてリアルタイムに動かしたい」と思ったのが始まりです。

動画用のコードは「同じ時刻を指定すれば必ず同じ絵になる」設計だったので、そのまま流用はせず、リアルタイム用に書き直しました。
